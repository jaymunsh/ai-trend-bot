# 브리핑 수집·요약·월별 기록 개선

사용자 승인: 2026-10-04 대화의 최종 실행 요청. 삭제/90일 만료는 취소했다.
2026-10-05 후속 승인: 무료 쿼터를 위해 요약은 기본 1회 요청, 운영 상한은 30건으로 되돌린다.

- miniPC는 07:15·13:15·19:15 KST에 준비를 시작한다. 같은 프로세스가 메모리로 결과를 보관해 07:30·13:30·19:30에 전송한다. 지연 완료 시 즉시 전송한다. 수동 실행/드라이런은 기본적으로 대기하지 않는다.
- GeekNews(50), The Decoder(10), Guardian AI(15) 추가. 총30출처, 후보 상한합435. Threads 경로 변경/추가 서버/후보 DB는 만들지 않는다.
- 발행 시간이 확인된 최근48시간 기사와 미발송 URL을 먼저 고르고, 최신순으로 소스별 상한을 적용한다. 날짜 불명은 날짜 불명으로 표시해 선별에 넘긴다. 잘못된 날짜/약간 미래 날짜는 경고 또는 허용범위를 명시한다.
- HN은 최근48시간·최신순으로 AI, LLM, OpenAI, Anthropic을 개별 조회하고 중복 URL을 합친다. 동작하지 않는 OR 문구와 과거 인기순 검색을 없앤다.
- 사건 중복은 기존 Gemini 판정 유지. 가격/성능/공개범위/조치 등 새 사실이 있는 후속 보도와 독립 회사 발표는 허용한다. 1차 병합 출처를 최종 선별 뒤에도 보존한다.
- 짧은 한국어 제목 + 사실1~2문장 + 원문 링크. 관행적인 중요성/관련대상 항목은 제거. 운영 및 CLI 최대30건, 목표량 아님. 요약은 기본1회 요청한다. 입력이10건을 초과하고 Gemini가 MAX_TOKENS로 중단됐다고 명시한 경우만10건 단위로 다시 요청하되 입력순서를 유지한다. 쿼터/네트워크/형식 오류는 분할 사유가 아니다. 전체 요약 성공 전에는 발송·기록하지 않는다.
- 발송 기록은 현재 `sent.jsonl`에 이번 달만 추가. 이전 달들은 같은 디렉터리의 `archive/until_YYYY-MM-DD.jsonl`에 보존. 월 경계는 KST. 기존 역사 파일도 월별 분리한다. 전체 보관 파일을 URL 중복/마지막발송/최근14일 사건 조회에 포함. 삭제/만료 없음.
- 월별 이전은 아카이브를 먼저 원자적으로 쓰고 활성 파일을 교체한다. 중간 실패 재실행에서 기록을 잃거나 중복 저장하지 않는다. 실제 발송 성공 메시지만 기록한다.
- 기사 HTML 문자열을 중간에서 자르지 않는다. 50건 메시지 분할/부분 전송 실패 기록은 유지한다.
- README/소개 페이지/운영 스크립트/수동 Actions에 최종 동작 반영. 실제 miniPC 반영은 연결 가능 여부와 분리해서 보고한다. API 키 출력과 실제 테스트 알림은 하지 않는다.
